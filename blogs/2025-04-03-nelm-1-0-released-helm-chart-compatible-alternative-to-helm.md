Initially, werf , a CNCF Sandbox tool for building containers and deploying to Kubernetes, was built upon our Helm 3 fork, which accumulated quite a few new features and fixes for Helm 3. However, some werf users were only interested in the deployment part of werf, without building containers and other non-deployment functionality. For these users we even maintained the werf helm … set of commands, which was basically our Helm 3 fork exposed.
